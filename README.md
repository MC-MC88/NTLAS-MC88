# 📱 Ntlas — Générateur de QR Code Professionnel Gratuit

**Ntlas** est un générateur de QR codes moderne, rapide et 100% gratuit qui fonctionne entièrement dans votre navigateur. Créez des QR codes pour des liens, des réseaux Wi-Fi et des cartes de visite virtuelles (vCard), personnalisez leur apparence et exportez-les en haute résolution.

---

## 📋 Prérequis

1. Un navigateur web moderne (Chrome, Firefox, Edge, Safari, Brave, Opera)
2. Aucune connexion Internet requise après le chargement initial de la page
3. Aucune installation de logiciel nécessaire

---

## 🚀 Guide d'installation complet

### Étape 1 : Télécharger le fichier

1. Téléchargez le fichier `index.html` sur votre ordinateur
2. Placez-le dans un dossier de votre choix (par exemple : `C:\Ntlas\` ou `~/Documents/Ntlas/`)

### Étape 2 : Lancer l'application

**Méthode simple (recommandée) :**
- Double-cliquez simplement sur le fichier `index.html`
- L'application s'ouvrira automatiquement dans votre navigateur par défaut

**Méthode alternative (pour les développeurs) :**
- Ouvrez votre éditeur de code (VS Code, Sublime Text, etc.)
- Ouvrez le dossier contenant `index.html`
- Utilisez l'extension "Live Server" ou similaire pour lancer un serveur local
- Accédez à `http://localhost:5500` ou `http://127.0.0.1:5500` dans votre navigateur

## 🎯 Guide d'utilisation détaillé

### 🔹 Étape 1 : Choisir le type de QR code

L'application propose **3 types de QR codes** :

#### 📝 Texte / Lien (Texte/Lien)
1. Cliquez sur l'onglet **"Lien/Texte"** (ou **"رابط/نص"** en arabe)
2. Collez une URL ou saisissez n'importe quel texte
3. Le QR code se génère automatiquement après 350ms d'inactivité

#### 📶 Wi-Fi
1. Cliquez sur l'onglet **"Wi-Fi"** (ou **"شبكة Wi-Fi"** en arabe)
2. Saisissez le **nom du réseau (SSID)**
3. Saisissez le **mot de passe**
4. Choisissez le type de sécurité :
   - **WPA/WPA2** : Sécurité standard (recommandé)
   - **WEP** : Ancienne sécurité
   - **Sans mot de passe** : Réseau ouvert
5. Le QR code permettra aux utilisateurs de se connecter automatiquement au Wi-Fi en le scannant

#### 👤 Contact (vCard)
1. Cliquez sur l'onglet **"Contact"** (ou **"جهة اتصال"** en arabe)
2. Saisissez le **nom complet**
3. Saisissez le **numéro de téléphone**
4. Saisissez l'**email** (optionnel)
5. Le QR code créera une carte de visite virtuelle scannable

---

### 🔹 Étape 2 : Personnaliser l'apparence

#### Forme du cadre néon
1. Dans la section **"Personnalisation"** (ou **"التخصيص"** en arabe)
2. Choisissez parmi 3 options :
   - **Aucun** : Pas de cadre
   - **Carré néon** : Cadre carré avec effet lumineux
   - **Rond néon** : Cadre circulaire avec effet lumineux

#### Couleur du néon
1. Cliquez sur le sélecteur de couleur **"Couleur néon"** (ou **"لون النيون"** en arabe)
2. Choisissez n'importe quelle couleur
3. L'effet lumineux s'adapte automatiquement

#### Couleur du QR code
1. Cliquez sur le sélecteur de couleur **"Couleur du QR"** (ou **"لون الرمز"** en arabe)
2. Choisissez la couleur des modules (carrés) du QR code
3. Le fond reste blanc pour une lisibilité optimale

#### Logo personnalisé
1. Dans la section **"Logo du QR"** (ou **"شعار الرمز"** en arabe)
2. Cliquez sur **"Changer"** (ou **"تغيير"** en arabe)
3. Sélectionnez une image depuis votre appareil
4. Le logo sera placé au centre du QR code
5. Formats acceptés : PNG, JPEG, WebP, etc.

---

### 🔹 Étape 3 : Configurer la qualité d'exportation

#### Taille (résolution)
1. Dans la section **"Qualité d'export"** (ou **"جودة التصدير"** en arabe)
2. Choisissez parmi 3 tailles :
   - **512 px** : Petit format (réseaux sociaux, signatures email)
   - **1024 px** : Format standard (impression, affiches)
   - **2048 px** : Haute résolution (grand format, print professionnel)

#### Format
1. Choisissez le format d'exportation :
   - **PNG** : Format sans perte, idéal pour les logos et QR codes (recommandé)
   - **JPEG** : Format compressé, plus léger mais avec perte de qualité

#### Qualité JPEG
- Si vous choisissez **JPEG**, un curseur de qualité apparaît
- Ajustez de 40% à 100%
- 92% est la valeur par défaut (bon compromis qualité/taille)

> **Note importante** : La taille et la qualité choisies s'appliquent **uniquement au téléchargement**, pas à l'aperçu à l'écran.

---

### 🔹 Étape 4 : Exporter le QR code

#### Télécharger (Sauvegarder)
1. Cliquez sur le bouton **"Télécharger"** (ou **"حفظ"** en arabe)
2. Le QR code sera téléchargé avec la taille et le format choisis
3. Une fenêtre de disclaimer s'affichera après le téléchargement

#### Partager
1. Cliquez sur le bouton **"Partager"** (ou **"مشاركة"** en arabe)
2. Si votre navigateur supporte le partage de fichiers :
   - Sur mobile : le menu de partage natif s'ouvrira (WhatsApp, email, etc.)
   - Sur ordinateur : le menu de partage du système s'ouvrira
3. Sinon, un message d'erreur s'affichera

#### Copier dans le presse-papiers
1. Cliquez sur le bouton **"Copier"** (ou **"نسخ"** en arabe)
2. L'image du QR code sera copiée dans le presse-papiers
3. Collez-la dans n'importe quelle application (Word, Canva, etc.)

---

### 🔹 Étape 5 : Utiliser les modèles prêts à l'emploi

L'application propose **3 modèles de composition** :

#### Carte de visite
- Modèle professionnel avec espace pour le nom et le site web
- Le QR code est placé à droite
- Idéal pour : cartes de visite, badges, étiquettes

#### Affiche / Flyer
- Modèle avec texte "SCANNEZ-MOI" en grand
- Le QR code est centré
- Idéal pour : affiches, flyers, panneaux publicitaires

#### Post réseaux sociaux
- Modèle carré avec dégradé de couleurs
- Le QR code est centré
- Idéal pour : Instagram, Facebook, Twitter, LinkedIn

**Pour utiliser un modèle :**
1. Générez d'abord votre QR code (remplissez les champs)
2. Cliquez sur **"Insérer mon QR"** sur le modèle souhaité
3. Le modèle avec votre QR code sera téléchargé en PNG
4. Vous pouvez ensuite le modifier dans Canva ou une autre application

## 🌐 Changement de langue

L'application est disponible en **2 langues** :

### Arabe (العربية)
- Cliquez sur le bouton **"العربية"** dans la barre de navigation
- L'interface passe en mode RTL (droite à gauche)
- Tous les textes, placeholders et boutons sont traduits

### Français
- Cliquez sur le bouton **"Français"** dans la barre de navigation
- L'interface passe en mode LTR (gauche à droite)
- Tous les textes, placeholders et boutons sont traduits

> **Note** : Les popups d'aide (?) sont toujours en français, comme demandé.

## 🎨 Thème sombre / clair

### Basculer le thème
1. Cliquez sur l'icône **soleil/lune** dans la barre de navigation
2. Le thème bascule entre sombre (défaut) et clair
3. Votre préférence est enregistrée automatiquement

### Détection automatique
- Au premier chargement, l'application détecte le thème de votre système
- Si votre système est en mode sombre, l'application démarre en sombre
- Si votre système est en mode clair, l'application démarre en clair

## 🛠️ Guide de dépannage (Problèmes courants)

### Problème 1 : Le QR code ne se génère pas

**Cause :**
- Le champ de saisie est vide
- La bibliothèque QRCode.js n'a pas été chargée

**Solution :**
- Vérifiez que vous avez saisi du texte, un SSID Wi-Fi ou un nom de contact
- Vérifiez votre connexion Internet au premier chargement
- Rechargez la page (F5)

---

### Problème 2 : Le bouton "Télécharger" ne fonctionne pas

**Cause :**
- Aucun QR code n'a été généré
- Le navigateur bloque les téléchargements automatiques

**Solution :**
- Générez d'abord un QR code en remplissant les champs
- Vérifiez les paramètres de téléchargement de votre navigateur
- Autorisez les téléchargements multiples pour ce site

---

### Problème 3 : Le logo ne s'affiche pas sur le QR code

**Cause :**
- Le fichier image n'a pas été chargé correctement
- Le format d'image n'est pas supporté

**Solution :**
- Réessayez avec un autre fichier image
- Utilisez un format PNG ou JPEG
- Vérifiez que le fichier n'est pas corrompu

---

### Problème 4 : Le QR code Wi-Fi ne fonctionne pas au scan

**Cause :**
- Le SSID contient des caractères spéciaux
- Le type de sécurité est incorrect

**Solution :**
- Vérifiez que le SSID est exactement le même que celui du réseau
- Essayez un type de sécurité différent
- Évitez les caractères spéciaux dans le SSID si possible

---

### Problème 5 : Le partage ne fonctionne pas sur mon appareil

**Cause :**
- Le navigateur ne supporte pas l'API Web Share
- L'API Web Share ne supporte pas les fichiers sur cet appareil

**Solution :**
- Utilisez le bouton "Télécharger" à la place
- Téléchargez puis partagez manuellement le fichier
- Essayez un autre navigateur (Chrome mobile est recommandé)

---

### Problème 6 : La copie dans le presse-papiers échoue

**Cause :**
- Le navigateur ne supporte pas l'API Clipboard avec images
- Les permissions sont bloquées

**Solution :**
- Utilisez le bouton "Télécharger" à la place
- Autorisez l'accès au presse-papiers dans les paramètres du navigateur
- Essayez Chrome ou Edge (meilleur support)

---

### Problème 7 : Le thème ne reste pas après rechargement

**Cause :**
- Le stockage local est désactivé
- Navigation privée/incognito

**Solution :**
- Vérifiez que le stockage local est activé dans le navigateur
- En navigation privée, le thème sera réinitialisé à chaque session
- C'est un comportement normal de la navigation privée

---

### Problème 8 : La langue ne change pas

**Cause :**
- Problème de cache navigateur
- JavaScript désactivé

**Solution :**
- Videz le cache du navigateur
- Rechargez la page avec Ctrl+F5 (Windows) ou Cmd+Shift+R (Mac)
- Vérifiez que JavaScript est activé

## 📝 Notes techniques

- L'application fonctionne 100% côté client (aucun serveur requis)
- Les données saisies ne quittent jamais votre navigateur
- Aucune donnée n'est envoyée sur Internet
- Les QR codes sont générés avec le niveau de correction d'erreur **H** (30%)
- Le niveau H permet de récupérer le QR code même avec un logo au centre
- L'aperçu à l'écran est en 220px pour des raisons de performance
- L'exportation utilise la taille choisie (512, 1024 ou 2048 px)
- Les modèles sont générés en 1000x1000 px
- La détection automatique du thème utilise `prefers-color-scheme`
- Le mode RTL/LTR s'adapte automatiquement selon la langue
- Les popups d'aide sont toujours en français
- Le disclaimer s'affiche après chaque téléchargement ou utilisation de modèle
